# Section types

Every section you can add to a page, with its layouts and settings. Settings marked *(… only)* appear only for those layouts. "On/off" settings show or hide part of the section. Their sub-settings appear when they're on.

![The section library](images/section-library.png)

Every section also has a **Background** (Page, Tinted, Brand or Dark). See [Edit a section](04-edit-section-content.md#change-the-background).

## Navigation Bar

*Logo, product links and sign-in actions.*

| | |
|---|---|
| **Available on** | Every page with site navigation (shared) |
| **Layouts** | Centered links |
| **Default background** | Tinted |

**Settings**

- **Logo** (image)
- **Nav links**: list, up to 7. Each item: Label, Link, Open in new tab, Visible to, Permission role, User group, Dropdown menu (switch).
  - **Dropdown items**: list, up to 8. Each item: Label, Link, Open in new tab, Visible to, Permission role, User group.
- **Login link** (on/off): Label, Link, Open in new tab, Visible to, Permission role, User group
- **Sign-up button** (on/off): Label, Link, Open in new tab, Visible to, Permission role, User group
