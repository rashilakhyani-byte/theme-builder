# Interface reference

A map of every part of the builder, its controls, keyboard shortcuts and limits.

![The builder](images/overview.png)

## Top bar

| Control | What it does |
|---|---|
| **Sidebar icon** | Shows or hides the portal's own navigation rail |
| **Undo / Redo** | Steps back or forward through changes |
| **Edit / Preview** | Switches between editing and seeing the page as a visitor |
| **Device switch** (Preview only) | Desktop, tablet or mobile width |
| **Publish Changes** | Publishes the portal |

## Left panel

| Part | What it does |
|---|---|
| **Page** | The page you're editing. Click to open the page menu: switch pages, turn pages on or off |
| **Palette icon** | Opens **Themes & Typography** |
| **Section list** | Header (navigation bar), the page's sections, Footer |
| **Section row** | Click to edit. Drag ⋮⋮ to reorder. **⋯** for Rename and Delete |
| **Eye** (Header/Footer rows) | Show or hide the navigation bar or footer |
| **+** next to the page name | Add a section at the end |
| **Breadcrumb** (← Home / Hero) | Back to the section list |
| **Add section** | Opens the section library |

### Section settings

| Group | Contents |
|---|---|
| **Layout** | Image-only layout cards. Hover for the layout name |
| **Background** | Page, Tinted, Brand, Dark |
| **Group cards** (e.g. *Content details*) | Open a popup with that group's fields. The second line lists the fields |
| **Button cards** | Switch shows or hides the button. Click to edit its label and link |
| **Lists** | Item cards with ⧉ duplicate. Click an item to edit it. **Add …** adds one |
| **Delete section** | Removes the section (undoable) |

### Edit popup

Opens beside the panel. Edits apply as you type. Close with **Done**, **×**, **Esc** or by clicking outside. List items also have **Delete**.

## Canvas

| Action | Result |
|---|---|
| Click a section | Selects it and opens its settings |
| Click text, a button or an image | Selects it and opens the popup for its fields |
| Double-click text | Edits the text in place |
| Hover between sections | Shows **Add section** for that spot |
| Drop a library card between sections | Adds that section there |

**Section tag** (above the selected section): name · layout, **Move up**, **Move down**, **Duplicate**, **Delete**.

## Keyboard shortcuts

| Shortcut | Action |
|---|---|
| **⌘Z** / **Ctrl+Z** | Undo |
| **⇧⌘Z** / **Ctrl+Shift+Z** | Redo |
| **Esc** | Close a popup or menu. Otherwise, go back to the section list |
| **Delete** / **Backspace** | Delete the selected section (when you're not typing) |
| **Enter** | Finish editing single-line text, or confirm a rename |
| **Esc** (while editing text) | Cancel the edit |

## Limits

| Item | Limit |
|---|---|
| Navigation links | 7 |
| Items in a navigation dropdown | 8 |
| Footer link columns | 4 |
| Featured API categories | 6 |
| Getting Started steps | 4 |
| Why Choose Us reasons | 4 · Bento statements: 5 · Use-case industries: 5 · Recipes: 4 · Stats: 4 |
| Resources articles | 4 |
| Award highlight cards | 4 |
| Corner radius | 0 to 24 px |
| Image uploads | PNG, JPG or SVG |
| Font uploads | .woff2, .woff, .ttf, .otf |
| Undo history | Last 60 changes |
