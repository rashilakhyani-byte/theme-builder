# Start from a template

The first time you open the builder, it asks how you want to start. You can begin from a ready-made template or from a blank page. Either way, everything stays editable.

![The Start your portal window](images/template-picker.png)

1. **Templates**: each card is a different starting page.
2. **Preview**: the whole page the selected template creates, at full size.
3. **Create From Scratch**: just a navigation bar and footer, with an empty page between them.
4. **Use This Template**: starts with the selected template.

## Start from a template

1. Click **Customise** in the portal's left rail. The **Start your portal** window opens.
2. Click a template card on the left, then scroll the preview to check the whole page.
3. Click **Use This Template**.

The builder opens with the template's sections on your Home page, in the template's colour, style and fonts.

## Start from scratch

1. In **Start your portal**, click **Create From Scratch**.
2. The Home page opens with only the navigation bar and footer. Click **Add section** to add your first section (see [Manage sections](03-manage-sections.md)).

## Choose between the templates

| Template | Best for | What's on the page |
|---|---|---|
| **Full portal**: *Everything, in the recommended order* | A complete launch page | Hero, awards, APIs, onboarding, solutions, resources and FAQ |
| **API catalogue**: *Lead with the catalogue* | Teams selling APIs | The product up front, then categories, a live try-out and pricing-style FAQs |
| **Partner launch**: *Built to win partners* | Recruiting partners | Recognition, reasons to build with you, the onboarding path and an enquiry form |
| **Docs first**: *Quiet, technical, fast to read* | Documentation-led products | Product shot, steps, capabilities and answers |

> **Note:** close the window with **×** and you'll see an empty canvas behind it. The start window comes back the next time you open the builder, until you choose a template or start from scratch.
